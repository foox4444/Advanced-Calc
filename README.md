# Calculator
A calculator. My inspiration comes from my geometry grade being... (I might make a graphing calculator as an update) I used VS Code and Python. I made it using Tkinter. I had to fix a lot of typos, and I struggled a little while implementing the order of operations. I tried to add more features without making it too complex, so I added themes since I use dark themes all the time. The features include: order of operations, parentheses, exponents, basic math functions, memory, history, themes, and clipboard. To open the calculator, download main.py, then run the code.
