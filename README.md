# Calculator
A calculator. My inspiration comes from my geometry grade being... (I might make a graphing calculator as an update)
I used VS Code and Python. I made it using Tkinter. I had to fix a lot of typos, and I struggled a little while implementing the order of operations.
I tried to add more features without making it too complex, so I added themes since I use dark themes all the time.
The features included:
Order of operations, parentheses, exponents, basic math functions, memory stuff, history, themes, clipboard
